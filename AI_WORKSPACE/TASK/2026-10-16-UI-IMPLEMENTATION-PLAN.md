## 授权和执行方式

- 已授权修复开发环境、在工作分支开发、运行检查、提交及创建草稿 PR。
- 日常实现细节自主推进；与 UI 要求冲突时暂停受影响部分并报告，其余独立工作继续。
- 不直接修改 main、不合并、不发布、不构建 Release APK。
- 以一个可验证目标为一批，不同时铺开多条业务链；按实际依赖调整顺序并记录原因。
